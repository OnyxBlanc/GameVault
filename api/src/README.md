# Modules de l’API
- Auth : inscription, connexion, déconnexion et profil.
- Catalogue : cartes, genres, plateformes et raretés.
- Boosters : boutique, filtrage par thème, tirage et ouverture transactionnelle.
- Collection : quantités et complétion.
- Admin : gestion des cartes, boosters et taux.
- Rawg : import serveur en phase 2.
Pour chaque module, séparer contrôleur HTTP, service métier et accès aux données.
